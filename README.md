# bohmian-code-review

Rust helpers for in-memory symbolic context in a no-clone code-review service. The first planned capability is a two-pass file picker: extract symbols from caller-supplied blobs, then rank context files from changed-line references under a token budget.

The workspace holds six crates (`bohmian-code-review-core`, `-extract`, `-index`, `-resolve`, `-select`, and the `bohmian-code-review` facade). Core facts and the complete tree-sitter extractor are ported; index, resolver, selector, and facade behavior are pending. Run `mise run test:extract` for the extractor and its copied fixture corpus. Licensing: [MIT](LICENSE); ported code and vendored grammars are listed in [third-party notices](THIRD_PARTY_NOTICES.md). The [active specification](changes/active/review-helper-setup/spec.md) is approved; the [implementation handoff](changes/active/review-helper-setup/implementation-plan.md) records the intended repository, crate, and journey setup. [Architecture](architecture/bohmian-code-review-design.md) and [contributor rules](AGENTS.md) are repository authority. Canonical agent skills live in `.agents/skills`; `.claude/skills` is generated from them.
