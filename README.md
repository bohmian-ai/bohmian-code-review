# bohmian-code-review

Rust helpers for in-memory symbolic context in a no-clone code-review service. The first planned capability is a two-pass file picker: extract symbols from caller-supplied blobs, then rank context files from changed-line references under a token budget.

The workspace holds six crates (`bohmian-code-review-core`, `-extract`, `-index`, `-resolve`, `-select`, and the `bohmian-code-review` facade). Core facts and the complete tree-sitter extractor are ported; the index, resolver, selector, and facade compose them into an in-memory two-pass symbolic-context journey. The outer `bohmian-code-review-pipeline` crate adds GitHub access and injected storage; consumers start with `ReviewPipeline` (`context`, `refresh`, `read`) over one object storage and one store, and the stage facades stay public for advanced callers. Run `mise run gate` for formatting, lints, type-check, every component lane, the public journey, and skill-mirror sync; CI runs the same task.
