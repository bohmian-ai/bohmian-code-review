## SNAPSHOT-008-R3-1 — indexed-empty snapshot remains reusable

- **Classification / prior finding:** INCORRECT, `FIND-008-2` class incomplete. The task contract says an indexed outcome carries at least one persisted declaration; a successful no-declaration file is `NoFacts` with its verified blob. The maintainer requires this invariant by outcome shape, not another caller guard.
- **Root cause and defect class:** The durable `Snapshot` still separates `facts`, `coverage.indexed`, and `coverage.skipped` into independently representable values, and an `IndexedFileFacts` may contain zero declarations. `Snapshot::decode` calls the numeric completeness check without making the indexed/no-facts state unrepresentable. The new facade boolean and `Ingest::settle` branch classify newly ingested or update-reused files, but cannot change a previously published same-tree object.
- **Reproduction by source trace:** The round-two candidate produced an import-only `IndexedFileFacts` with empty declarations and counted it indexed; it used the same `recovered-tree.facts-2` extraction version as HEAD. Such a previously published object has a valid digest, matching identity/tree/version, and numerically complete coverage. `Snapshots::read` therefore decodes it. With the default branch still at that tree, `ColdBuild::build` returns `Reused` with its old coverage before `Ingest::reuse` can normalize the file. The public read path can likewise return the old object. This is a reachable warm call after deployment of the correction, not a fabricated malformed object.
- **Sibling sweep:** The same-tree cold-build path is `ColdBuild::run` → `build` → `Snapshots::read` → `Snapshot::decode` → `Reused`. `Update::run` at the same tree delegates to `build`; `PrContext::snapshot` reads the same object before its overlay normalizes via `Ingest::reuse`. The latter yields corrected invocation-local overlay facts but does not repair the published pointer or cold-build coverage. Fresh archive, blob fallback, update at a different tree, and PR head ingestion share `Ingest::settle` and do classify no-facts correctly. No separate new classifier was found.
- **Observable consequence:** The cold-build facade can continue returning complete, indexed coverage for an import-only file without a `NoFacts` skip or declaration, while the immutable pointer and read-back retain that false status indefinitely at an unchanged tree. R2's update/reuse unit test bypasses this same-tree pointer path.
- **Testable correction:** Make the candidate-owned persisted indexed/no-facts outcome shape agree with the declaration projection, and ensure a same-tree pointer produced under the old representable shape cannot be accepted as a current complete snapshot. Preserve versioned immutable publication, verified path/blob identity, and non-benign failure categories. A focused fake-store test should start from the prior candidate's valid digest/pointer and indexed-empty record, call cold build at the same tree, and prove the resulting current snapshot has a `NoFacts` skip with that blob and no indexed-empty fact record; also cover read-back and update's same-tree route. Do not add downstream guards.
