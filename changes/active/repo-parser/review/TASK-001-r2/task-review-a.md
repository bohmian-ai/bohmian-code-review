- Real export failing its own validation: swept `crates/bohmian-code-review-extract/tests/fixtures` and `tools/oracle` JSON for declarations with empty `id`/`name`/`qualified_name` or `start_line: 0`; none. - Duplicate `MatchReason` when two changed files reference the same name: `resolve` collects names into a `BTreeSet` first, so each name is looked up once; the journey's `single.files[0] == ranked[0]` equality would have caught it.
- Config-dependent eligibility (`.h` with C disabled but C++ enabled would report `None`): unreachable through the public facade, which only constructs `all_native()`.
- Drift ladder on each new item: `DeclarationFact` (needed for source-free projection), `IndexedFileFacts.extraction_version` per record (needed for load-time refusal), `ChangedBlob` (bytes level) vs `ChangedFile` (facts level) live on different sides of extraction, `Language` re-export (needed for `path_language` return), `serde_json` dev-dep (JSON round-trip and fragment-leak assertion). Nothing is deletable without losing a required behavior.
