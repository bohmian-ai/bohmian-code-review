# Architecture authority

`bohmian-code-review-design.md` owns the product and crate boundaries, public workflow, and semantic selection contract. `agent-rules.md` owns implementation constraints. `references/README.md` routes to focused engineering guidance; references do not override either authority. `AGENTS.md` is the contributor entry point. Active change specifications and tasks live under `changes/active/`; completed records live under `changes/completed/`.
